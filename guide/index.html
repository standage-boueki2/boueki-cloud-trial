はじめてのログイン

STANDAGEからお渡しするアクセスコードと、お名前で入ります。PCでもスマホでも、ブラウザから使えます。

  1. アクセスコードを入力します（例：BC-XXXX-XXXX）
  2. お名前を入力します。招待されたメンバーは、招待されたときの氏名で入ります
  3. オレンジのボタンを押して開始します
  4. 表示の言語は、日本語・English・中文・Español から選べます
  5. はじめてのときは「3つのステップ」が表示されます：資料を入れる → 質問に答える → AIに聞く・任せる画面2
  6. 「さっそく始める」で、商品の登録に進みます画面2

商品・書類などのデータは、サーバーに預ける前に端末で暗号化します。作業中の控えはこの端末のブラウザに置き、ログアウトすると消えます（タブを閉じただけでは残ります）。共用の端末では、使い終わったらログアウトしてください。最後の操作から3時間で自動的にログアウトします。

足りない情報を、AIと一緒に埋める

資料にない項目は、AI商社マンが大事な順に1つずつ質問します。分からない項目は、飛ばしてかまいません。

  1. 充足度は、貿易クラウドがどこまで動けるかの目安です。4つの枠は「何のために必要か」を示します
  2. AIの質問には、その項目が何に使われるかも書いてあります（例：HSコード → 関税率・必要書類の判定）
  3. 答えを入力してEnter。資料の追加やURLからの取り込みもここからできます
  4. 分からないときは「わからない（あとで）」。HSコードは「不明」と答えると候補を出します
  5. 右上の「残り N項目」で、あといくつ答えれば完成かがわかります

こんな入力もできます

「NETとGrossどちら？」と質問したり、「商品名を〇〇に変更して」と修正を頼んだりできます。AIが答えてから、続きを聞きます。

8操作ガイド

バイヤーネットワークで相手を探し、つないでもらう

条件に合う相手に、STANDAGEが貴社をご紹介します。相手が承諾すると、連絡先が貴社にだけ開示されます。

  1. 見える範囲は3つ：公開情報／STANDAGEネットワーク／貴社専用（貴社の相手は他社に見えません）
  2. 国・カテゴリ・業態で絞り込み、件数を確かめます
  3. 一覧は匿名で、名前・連絡先・他社との商談の状況は出ません
  4. 気になる相手の「つなぐ依頼」を押します
