# 貿易クラウドAI商社マン（デザイン刷新版）使い勝手評価：操作の手引き

## 何を評価するか
- 対象：`貿易クラウドAI商社マン` の **デザイン刷新版**（本体 21.91 ＋ 見た目の層 `rd/`）。ローカルで `http://127.0.0.1:8801/` に立ててある（止めない・再起動しない）。
- 中小企業が輸出を進めるための SaaS。荷主（輸出する会社）・物流会社・管理者（STANDAGE）の3つの立場がある。
- 評価は **実際に画面を操作して** 行う（コードを読んで想像で書かない）。操作は Playwright（Chromium）で、下のヘルパーを使う。

## 道具（`tools/lib.cjs`）
作業フォルダ（スクリプト・画像・結果）は自分専用のフォルダだけを使う。`tools/` と リポジトリのファイルは書き換えない。

```js
// 例：/tmp/.../scratchpad/agents/<自分のID>/s01.cjs
const L = require('<このフォルダ>/tools/lib.cjs');
(async () => {
  const { browser, page, log } = await L.open({
    profile: 'food_p1',                       // 同じ名前を渡すと前回の続き（登録した商品・設定が残る）。ペルソナごとに別の名前
    acct: { code: 'BC-FOOD-P101', co: '株式会社信州はちみつ工房', who: '田中 美咲' }, // ペルソナごとに別のコード
    // mobile: true,                           // スマホ（390×844）で開く
    // viewport: { width: 1280, height: 720 }, // 画面の大きさを変える
  });
  await L.enter(page);                        // 入る。はじめての窓（ようこそ・登録メニュー）は自動で閉じる。{ firstRun: true } で閉じずに残す
  await L.go(page, 'cty');                    // 画面を移る（キーは下の一覧）
  console.log(await L.text(page, '.stage'));  // 本文の文字（セレクタ省略で画面全体）
  console.log((await L.controls(page)).join('\n'));   // 見えているボタン・入力欄の一覧
  console.log(JSON.stringify(await L.overlays(page))); // 開いている窓（ダイアログ・トースト）
  await L.clickText(page, 'AI商社マンにおまかせ（1クリック）'); // 文字でボタンを押す（第3引数にセレクタで範囲）
  await L.shot(page, '/絶対パス/a.png');       // いま見えている範囲を撮る（第3引数 true で縦に全部）
  await L.shots(page, '/絶対パス/cty', 4);     // 上から画面ごとに区切って撮る（縦に長い画面はこちらが読みやすい）
  console.log(JSON.stringify(log));           // ページのエラー（errors）・警告（console）
  await browser.close();
})().catch((e) => { console.error(e); process.exit(1); });
```
- 見本を開く：`await L.loadSample(page, 'food')`。キー＝ `food`（食品・有機抹茶パウダー）`cosme`（化粧品・セラム）`parts`（工業部品・軸受）＝**完成形の見本**（2年分の商談つき）／`daily`（日用雑貨・タンブラー）`car`（中古車）`liquor`（酒類）`apparel`（アパレル）`medical`（医療・衛生用品）＝**業種サンプル**（登録直後の状態）。
- 自社の商品を資料で登録：`await L.registerByUpload(page, '商品情報_食品_food_honey.xlsx')`（`scratchpad/files/` の中のファイル名。中身は `files/products.json`）。そのあと画面の案内（「すべて登録する」「AIの質問に答える」など）に従って進める。
- ファイルを選ぶ欄に入れるときは `await L.setFiles(page, '#欄のID', 'ファイル名')`（**日本語名のファイルをパスで `setInputFiles` すると、この環境では無視される**ので必ずこの関数を使う）。
- 普通の Playwright の操作（`page.click`・`page.fill`・`page.keyboard`・`page.evaluate`）も使える。アプリの関数を `page.evaluate` で直接呼ぶのは、状況を調べるときだけ（利用者はボタンでしか操作できない。**評価はボタン・入力での操作で行う**）。
- 1回の実行は 90 秒以内を目安に短く区切る（`profile` で続きから再開できる）。ブラウザは同時に1つだけ。
- 画像は Read ツールで見られる。文字の確認は `L.text` のほうが安い。**表示崩れ（重なり・はみ出し・切れ）の確認は画像で**。

## この環境だけの事情（課題として数えない）
- **同期サーバーは代役**（最小限の応答）。メールの実送信・メンバー招待のメール・確認コード・実在の物流会社への依頼などサーバーが要るものは、最後まで動かなくてよい。ただし「そのとき画面が何と言うか（分かりやすいか・行き止まりにならないか）」は評価する。
- **AI は未接続**（外部の AI に届かない）。AI の答え・読み取り・生成は「内蔵エンジン」の代わりの結果になる。「AIエンジン未接続…」の注意書きそのものは課題にしない。内蔵の答えでも、**その業種・商品に合わない内容／矛盾／誤った数字**は課題として書く。
- 外部サイトへの通信（為替・Web検索・画像）は遮断される。それ由来の「取得できませんでした」は課題にしない（ただし利用者への伝え方が不親切なら書く）。
- 上の帯のすぐ下の「刷新版プレビュー（手元だけ…）今の版を開く」の札は社内確認用の表示（課題にしない）。
- 見本データの日付は 2026 年夏ごろ。きょうは 2026-11-14。

## 採点（画面ごと・ペルソナごとに 1〜5）
- 5：迷わず目的を達成できる。誤り・表示崩れ・数字の食い違いがない。言葉がその人に合っている。次に何をするかが分かる。
- 4：小さな引っかかり（文言・少しの戸惑い・軽い見た目の乱れ）はあるが、自力で進める。
- 3：はっきりした戸惑い・遠回り・不整合があり、説明やサポートが欲しくなる。
- 2：主な目的の達成が難しい。誤解を招く重大な問題がある。
- 1：目的を達成できない（動かない・行き止まり・エラー）。
5 にしなかった画面は、必ず「何が直れば 5 になるか」を具体的に書く。

## 課題の書き方（必ず事実だけ。見たままを書く）
- 再現手順（どの画面で・何を押して）／期待したこと／実際に起きたこと／証拠（画面の文言の引用、または画像のパス）。
- 重さ：`blocker`（先へ進めない）／`major`（誤解・やり直し・信頼を損なう）／`minor`（戸惑う・手間）／`polish`（見た目・文言の磨き）。
- 種類：`bug`／`ux`（導線・分かりにくさ）／`copy`（言葉）／`layout`（表示崩れ）／`data`（数字・内容の誤りや食い違い）／`missing`（その人に必要な機能・情報が無い）。
- 推測で書かない。確かめられなかったことは「未確認」と書く。良かった点も書く（残すべきもの）。
