**先に結論**
- 評価は途中までです。9つの評価担当（8カテゴリー＋物流会社・ログイン・スマホ・言語・管理者の横断）を並行で走らせましたが、利用量の上限に当たって全担当が途中で止まりました。**1人目のペルソナ（貿易素人）の操作は8カテゴリーとも深く終わり、物流会社の画面も確かめましたが、2人目・3人目（少し経験者・商社経験豊富）と、ログイン・スマホ・言語・管理者は、ほぼ未実施**です。
- 途中経過で見つかった課題は **166件**（重大 0・大 61・中 66・小 39）。21.92 で **53件を直し、39件は一部を直し、74件は未対応**です（一覧は [ISSUES.md](ISSUES.md)）。

## 評価のやり方
- 対象：刷新版（本体 21.91 ＋ `rd/` の層）をローカルで配り、Playwright（Chromium）で実際に操作。同期サーバーは最小限の代役（`tools/mock.cjs`）、AI は未接続（内蔵エンジンの答え）。
- 仮想ユーザー：見本の無い業種は、架空の会社の商品資料（`files/*.xlsx`）を登録して操作。
  - 食品＝はちみつ（資料）・酒（業種サンプル）・抹茶（完成形の見本）／生活用品＝タオル（資料）・タンブラー・デニム／工業・農業＝有機液体肥料（資料）・軸受／健康・美容＝乳酸菌サプリ（資料）・美容液／医療・衛生＝サージカルマスク（資料）・滅菌ガーゼ／自動車・建機＝中古油圧ショベル（資料）・中古車／文化・教育＝書道セット（資料）・資料なしの登録／その他＝ペット用品（資料）ほか

- 提出物：`findings/<担当>.json`（課題ごとに再現手順・期待・実際・証拠・重さ・直し方の案）と `.md`（要約）。**途中で書き出した時点のもの**です。

## 21.92 で直したこと
本体の層（今の版・刷新版の両方に効く）：`layers/logic_v2192cat.ts`・`layers/logic_v2192per.ts`／刷新版の層：`rd/rd_v92per.js`・`rd/rd_v92per.css`。今の関数は包むだけ（中身は変えていません）。

**8つの商材カテゴリー（logic_v2192cat）**
1. 業種サンプルを5つ追加：農業資材（有機液体肥料）・健康食品（乳酸菌サプリ）・建設機械（中古油圧ショベル）・文化・教育用品（書道セット）・ペット用品（猫用爪とぎ）。どのカテゴリーにも見本が1つ以上あります（すべて架空）。
2. 「サンプルで試す」の窓を、8つのカテゴリーごとに並べる。
3. 商材カテゴリーの選択肢に 農業資材・健康食品・建設機械・文化・教育用品・ペット用品 を足し、AI ヒアリングでは8つのカテゴリーごとにまとめて出す（これまでの選択肢は1つも消していません）。
4. 読み取り：資料の「商材カテゴリ」の欄が大カテゴリーの名前（健康・美容／自動車・建機／工業・農業 …）だけのとき、品名と HS から細かいカテゴリーを決める（サプリ＝健康食品、油圧ショベル＝建設機械、肥料＝農業資材）。決められないときは決めつけずに選択肢で聞く。「ペット用品（猫用の爪とぎ・段ボール製のベッド）」の「ベッド」で家具に振り替えない。
5. 足したカテゴリーの扱い：バイヤーの数は Ver.1 の近い区分で数える（文化・教育用品／ペット用品／農業資材＝その他、建設機械＝中古車・車両）。営業資料の型は 玩具・文具・ホビー／ペット用品／飼料・農業資材／サプリ・健康食品／医療 を選ぶ。成分・材質の表の見出しをカテゴリーに合わせる。

**使い勝手（logic_v2192per）**
6. AI ヒアリング：「AIの質問に答える」「AIと埋める」で答える欄まで送り、答えたあとも答える欄が見える位置を保つ。
7. 取引条件（建値）の質問は、インコタームズでない答え（産地など）を登録せず聞き直す。
8. 「社内規制DB」：社員でないアカウントには、いま使える調べ方（AI の詳細調査・AI商社マン・STANDAGE の担当に頼む）を案内する窓に（社員は今のまま）。
9. 規制を調べる：日本の輸出の禁止・規制措置の対象になりうる国・地域を選んだときの注意（国の選択欄に出る国が対象）。
10. 販売先国：表のチェックは3か国まで（4つ目は理由を出して入れない）。登録の無い「開拓しない国」の欄は本題の下へ。データが無いだけの観点を「先行者不在＝開拓型」と言い切らない。
11. 商品情報「④ 業種ごとの項目」の先頭に「取引の基本条件」（取引条件・支払条件・仕出港・産地・認証・期限/保証）を出し、その場で直せる。医療・衛生／建設機械／農業資材／生活用品／文化・教育用品／ペット用品 の項目（任意）を追加。
12. 資料の読み取り：「商品の強み1〜3」の行と、価格の欄に書いた建値・仕出港（例：¥1,450／本（FOB 横浜・税抜））を拾う。
13. 登録メニューを「閉じる」と登録済みの商品が隠れる → 登録済みの商品の表示に戻す。読み取り直後の「未反映」の帯に「すべて登録する／反映して進める はどちらか一方で大丈夫」と明記。
14. 「調査済みの仕向国 … 関税率と必要書類を紐付け済み」→ 表が「要確認」のときは、実際の状態に合う言い方に。
15. 物流レートの手入力：正の数でない運賃は登録しない（全角の数字は半角にそろえる）。レートの削除と、HS 候補「◯◯ にする」は、確かめてから。

**刷新版の画面（rd_v92per）**
16. 販売先国：データの無い観点は「0」（赤）ではなく「未評価」。レーダーも未評価の観点に線を引かない。国の詳細を開いている間は上のカードをたたみ、詳細の見出しが見える位置に。
17. 「？ 説明」が2つ並ぶ所を1つにまとめる。左メニュー「すべての機能」の札が字に重なる → 右上の角へ。
18. タスク（今日やること）の「停滞中の案件」：札は全件の数（一覧は3件＋「ほか N件」）。
19. AI ヒアリングの箱：商材カテゴリーの質問は8つのカテゴリーで見せる。選択肢は「例」の見た目に。切れた質問には「…」。
20. 右下の「AI商社マンに聞く」：下へ送ると丸い小さなボタンになる（重なる面積を減らす）。画面のいちばん下に余白。
21. はじめての窓の「オレンジのバー」の文を、刷新版の言い方（見出しの右の「次は」）に。
